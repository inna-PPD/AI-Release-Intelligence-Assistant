# Changelog: описи інструментів агента

## v2 — 2026-11-21
- `create_ticket`: «title і description сформулюй САМ з опису проблеми — не проси користувача їх писати; перепитуй лише version і severity». У v1 «короткий заголовок, мовою користувача» модель прочитала як «заголовок має дати користувач» і не створювала тікет навіть з усіма даними (a11, a12, a14 у першому прогоні).

## v1 — 2026-11-21
- Перша версія: `search_docs`, `get_release`, `list_defects`, `get_defect`, `create_ticket`.
- У кожному описі є «коли викликати / коли ні» та що повертає; межа між `search_docs` (документи) і трекером (`get_release`, `list_defects`) прописана явно, бо обидва знають про релізи.
- `create_ticket`: позначено як дію з побічним ефектом; «не вгадуй версію і severity — перепитай». Підтвердження людиною і перевірка, що версію назвав користувач, стоять у коді (`src/agent/loop.py`), а не лише тут.
