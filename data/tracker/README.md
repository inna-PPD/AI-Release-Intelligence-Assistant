# Трекер релізів і дефектів Contoso (синтетичні дані)

Імітація внутрішнього трекера (як Azure DevOps / Jira) для агента кейсу 3. Компанія Contoso вигадана.

- `releases.json` — 7 релізів Contoso Procurement. Дати й solution узгоджені з release notes у корпусі кейсу 2 (`data/corpus`): 1.4.2–1.5.2 випущені; 1.5.3 у тестуванні, 1.6.0 запланований — **дати релізу немає**, тож агент не має її вигадувати.
- `defects.json` — 12 дефектів. DEF-101…DEF-107 відповідають виправленням і відомим проблемам з release notes; DEF-108…DEF-112 є лише в трекері (документи про них не знають).
- Поле `team`: `procurement` — команда користувача агента; `finance` — чужа команда. Доступ до її дефектів закритий (крок 2, MCP-сервер повертає «немає доступу»).

Створені агентом тікети пишуться не сюди, а в `runtime/tickets.json` (не в git) — це дія з побічним ефектом, виконується лише після підтвердження людиною.
